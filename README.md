# Слияние Шивы и Шакти — демо

Демо-версия мини-приложения трансформационной игры «Слияние Шивы и Шакти» (RU / EN).

Всё приложение — один файл `index.html` плюс `art.jpg` (обложка) и `voice.mp3` (временная запись голоса).
Данные игрока хранятся в браузере (localStorage). Регистрация в демо отключена (`AUTH_ENABLED=false`).

## Публикация на GitHub Pages
Settings → Pages → Build and deployment → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/<имя-репозитория>/`.
